Combined Feature Set

The platform has two user types:

User — can act as either a Provider or Seeker depending on the transaction.
Driver — a separate interface focused on shared-route logistics.

This keeps the product simple: a hospitality business can list resources when it has surplus and request resources when it needs them, using the same account.

1. User — Provider & Seeker
1. Account & Profile
Sign up / Login
User profile
Business/contact details
Location
2. Manage Resources

Users can act as Providers by:

Add resource
Name/category
Quantity
Price
Description
Photos
Edit/remove resources
Set resource availability
3. Create & Manage Requirements

Users can act as Seekers by:

Describe requirements in natural language
Specify quantity, date/time, location, budget and delivery requirements
Edit/cancel requirements
View active requirements
4. Discover & Match

The platform matches seekers with suitable providers based on:

Resource type
Quantity
Availability
Price
Distance
Provider rating
Delivery requirements

Users can:

View matching resources/providers
Filter/sort results
View resource details
View provider profile, ratings and reviews
View available logistics options
5. Requests & Negotiation

Users can:

Receive resource requests when acting as a Provider
Send requests when acting as a Seeker
Accept/reject requests
Make and respond to counter-offers
Negotiate price and terms
6. Booking & Logistics

Once an agreement is reached:

Confirm booking
Select/assign suitable logistics
View driver and delivery details
Track booking/delivery status
Confirm pickup/handover
Upload pickup condition photos/videos
7. Escrow & Payments
Make/receive payments
View escrow status
View transaction amount and breakdown
Confirm successful fulfillment
Release payment after completion
Apply agreed deposit/penalty rules where applicable
8. Ratings & Reviews

After completing a transaction:

Rate the other user/provider
Leave a review
View ratings and reviews
Provider ratings contribute to future matching/search results
9. Notifications
New matches
Resource/booking requests
Negotiation updates
Booking confirmation
Driver assignment
Delivery updates
Payment/escrow updates

Delivery requirements

Accept/reject delivery requests
